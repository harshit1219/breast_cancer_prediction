# 🩺 Breast Cancer Prediction using Neural Network

A Machine Learning and Deep Learning project that predicts whether a breast tumor is **Benign** or **Malignant** using an Artificial Neural Network (ANN) built with TensorFlow and Keras.

## 📌 Project Overview

This project uses the Breast Cancer Wisconsin Diagnostic Dataset to train a Neural Network model capable of classifying tumors into two categories:
- **Benign (Non-Cancerous)**
- **Malignant (Cancerous)**

The dataset is preprocessed using feature scaling, and the model is trained using TensorFlow/Keras.

---

## 🚀 Features

- Data preprocessing using Pandas
- Feature Scaling with StandardScaler
- Train-Test Split using Scikit-learn
- Artificial Neural Network (ANN)
- TensorFlow & Keras implementation
- Model Accuracy Evaluation
- Accuracy & Loss Visualization
- Predicts whether a tumor is Benign or Malignant
